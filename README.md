# Workforce Attrition & Compensation Analysis

## Project Overview
Cleaned and analyzed a 22,000-row Human Resources dataset using PostgreSQL to uncover employee attrition drivers across departments, tenure brackets, age groups, and compensation bands, followed by interactive dashboard visualization in Power BI.

## Tools Used
* **SQL (PostgreSQL / DBeaver):** Data cleaning, standardization, filtering, and attrition rate aggregations.
* **Microsoft Excel:** Summary structuring and cross-checking.
* **Power BI:** Interactive dashboard with charts and dynamic slicers.
